CPU / EXECUÇÃO

ZeroCoding

Um assistente de programação no terminal em que contexto, ferramentas e estado de sessão permanecem explícitos.

O projeto conecta modelos locais e APIs compatíveis a contexto selecionado pelo usuário, ferramentas para inspecionar código e sessões que podem ser retomadas. A parte importante não é apenas chamar um modelo, mas manter claro o que ele sabe, o que pode fazer e em qual estado a sessão está.

RUNTIME
Python / terminal
MODEL
Ollama / OpenAI-compatible
CONTEXT
selecionado pelo usuário
TOOLS
read / tree / grep
STATE
sessões retomáveis

Execução depende do contexto que chega até ela.

RAM / PRESSÃO DE MEMÓRIA

Fenrir

Um daemon Linux que observa pressão de memória antes de decidir se deve intervir.

O sistema acompanha memória, swap e PSI e aplica políticas graduais sobre workloads usando cgroup v2. Simulação, opt-ins independentes, journal e rollback mantêm cada intervenção observável e reversível.

RUNTIME
Rust / Linux
SIGNALS
memory / swap / PSI
CONTROL
cgroup v2
POLICY
gradual / dry-run
RECOVERY
journal / rollback

O problema não é apenas quanto de memória está sendo usado, mas como o sistema chega até esse estado.

Training App

Aplicação mobile em que sessões e histórico continuam disponíveis sem depender da rede.

SQLite mantém os dados do produto localmente. Exportação, validação e restauração de backup fazem parte do mesmo modelo de persistência, em vez de serem tratados como recursos separados adicionados depois.

DISPLAY / PIPELINE VISUAL

ZeroInsight

Um fluxo que transforma briefing e contexto de marca em uma sequência visual reproduzível.

O processo separa estrutura, direção visual e geração para que cada execução preserve decisões anteriores e produza assets que possam ser revisados. O objetivo não é apenas gerar uma imagem, mas deixar o caminho até ela explícito.

DIRECTION

STACK

Uma saída visual é mais útil quando também é possível reconstruir as decisões que produziram ela.
