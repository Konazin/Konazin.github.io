ZeroCoding

Assistente de programação experimental para terminal, com contexto explícito e sessões locais.

MVP em Python com provedores locais Ollama e APIs compatíveis, habilidades Markdown e comandos para ler e buscar no projeto. Arquivos não entram no contexto automaticamente; edição, shell e ciclos autônomos ainda estão fora do escopo.

RAM / PRESSÃO DE MEMÓRIA

Fenrir

Daemon Linux para observar pressão de memória e simular políticas reversíveis por sessão.

Observação e simulação são o padrão; mudanças exigem opt-ins independentes. O controle experimental grava apenas memory.low por sessão, com journal e rollback. Não encerra processos, congela tarefas nem ajusta sysctls.

RUNTIME
Rust / Linux
SIGNALS
memory / swap / PSI
CONTROL
cgroup v2
POLICY
observe / dry-run
RECOVERY
journal / rollback

O modo padrão observa sem alterar o sistema.

Training App

App mobile local-first para treinos, com sessões e histórico disponíveis offline.

O app Expo/React Native guarda os dados no dispositivo com SQLite e inclui exportação, validação e restauração de backups. API Java/PostgreSQL e cliente web existem como componentes opcionais, fora do runtime mobile padrão.
